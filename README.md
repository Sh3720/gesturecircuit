# GestureCircuit 3D

**An Interactive Virtual Laboratory for Electronics & Physics**

GestureCircuit 3D is a browser-based learning platform that combines 3D visualization, hand gesture recognition and interactive physics experiments.

🚀 **Live Demo:** https://gesturecircuit.netlify.app/

## Features

### ⚡ Electronics Studio
- Build 3D electronic circuits using virtual components.
- Control components using webcam-based hand gestures.
- Connect circuits with interactive wires.
- Basic circuit validation and simulation.

### 🔬 Physics Practical Studio
- Single-Slit Diffraction
- Double-Slit Diffraction
- N-Slit Diffraction Grating
- Interactive sliders and numerical inputs.
- Live fringe pattern visualization and intensity graphs.
- Real-time wavelength calculations and percentage error.

## Tech Stack

- JavaScript
- Three.js
- MediaPipe
- HTML5 & CSS3
- Vite

## Run Locally

```bash
# Clone the repository
git clone https://github.com/Sh3720/gesturecircuit.git

# Enter project directory
cd gesturecircuit

# Install dependencies
npm install

# Start development server
npm run dev
```

For production:

```bash
npm run build
```
